\title{\textbf{No Universal Winner: When Physics-Informed Neural\\
Cellular Automata Beat (and Lose to) PINNs and Neural\\
Operators on Partial Differential Equations}}

\author{Tharun Nanju\\
\small Neural-Cellular-Automatons / PI-NCA project}

\date{June 19, 2026}

\begin{document}
\maketitle

\begin{abstract}
We ask a deliberately uncomfortable question: can a \emph{local} Physics-Informed
Neural Cellular Automaton (PI-NCA) compete with Physics-Informed Neural Networks
(PINNs) and global neural operators such as the Fourier Neural Operator (FNO) for
learning the dynamics of partial differential equations (PDEs)? To answer it
honestly we first migrate a PyTorch PI-NCA codebase to JAX/Flax behind a
\emph{correctness gate} (the JAX ports are asserted equal to verbatim PyTorch
references before any new science is done), then build a correctness-gated suite of
eight 2-D PDEs and six 3-D PDEs and run every architecture through one shared
autoregressive-emulation protocol. The architectures span a conservative
flux-divergence PI-NCA (\texttt{DeepFluxNCA}), an unconstrained NCA, four motivated
hybrids (\texttt{MultiScaleFluxNCA}, \texttt{BoundedConsFluxNCA},
\texttt{SpectralFluxNCA}, \texttt{MultiChannelFluxNCA}), an FNO, and continuous
PINN/DeepONet baselines.

Our central empirical finding is that \textbf{there is no universal winner}. The PDE's
own structure --- whether it conserves mass, whether its field is bounded, how far
information propagates per step, and how much fine-scale content the solution carries
--- selects which inductive bias wins. A multi-scale conservative NCA wins smooth
local diffusion (heat, rel-L2 $0.0064$--$0.018$) at roughly $200\times$ better
parameter efficiency than an FNO; the FNO wins fine-scale, globally-coupled, and
non-conservative regimes (Allen--Cahn $0.0068$, Navier--Stokes $0.098$); the
unconstrained NCA wins non-conservative reaction systems (FitzHugh--Nagumo $0.125$);
and \emph{all} simple emulators fail catastrophically on stiff 4th-order Cahn--Hilliard
until an explicit output-bounding fix is applied --- a fix that in turn \emph{conflicts}
with exact conservation and must be reconciled by a bounded conservation-preserving
update. A spectral diagnostic explains the trade: NCAs place their residual error in
fine scales (high-frequency error fraction $0.44$--$0.89$) while the FNO's error is
broadband-flat ($0.004$), which is precisely why the FNO wins sharp-interface problems
despite the NCA's lower \emph{total} error on smooth ones. Crucially, the entire 2-D
regime map reproduces in full 3-D, making the architecture-vs-PDE-structure thesis
dimension-independent. We report all numbers under a single fixed seed with a
``start from a better point'' protocol, are explicit about the reduced-scale CPU
setting, and pass a 56/56 correctness gate.
\end{abstract}

\section{Introduction}
% ============================================================

Neural emulators for partial differential equations have become a crowded field. On
one side sit \emph{Physics-Informed Neural Networks} (PINNs), which fit a continuous
function $u_\phi(x,t)$ to a single initial-value problem (IVP) by minimizing the PDE
residual via automatic differentiation. On another side sit \emph{neural operators}
such as the Fourier Neural Operator (FNO) and DeepONet, which learn a map between
function spaces and generalize across initial conditions. And on a third, less
explored side, sit \emph{Neural Cellular Automata} (NCAs): grids of identical local
cells that update by a learned rule, much like a finite-difference stencil with
trainable weights.

The temptation, when one has built a clever NCA, is to argue that it is the best tool
for PDEs. We resist that temptation on purpose. The goal of this work is \emph{not}
to crown NCAs, but to characterize \emph{which method wins in which regime} --- and,
just as importantly, to document where NCAs lose, and why. An NCA is a fundamentally
\emph{local} machine: information moves at most one cell per step. A PINN is
\emph{continuous} but solves only one IVP at a time. An FNO is \emph{global} in one
layer but pays for it with parameters and a smoothing spectral truncation. These are
not competing implementations of the same idea; they are different inductive biases.
The interesting scientific question is whether a PDE's \emph{character} can predict
which bias will win.

\paragraph{The intuition in one paragraph.} Think of a PDE as having a personality.
Some PDEs are \emph{local and conservative}: heat diffuses, and the total amount of
heat does not change. For those, a local cellular automaton that is built to conserve
mass is a near-perfect match --- it does exactly the kind of book-keeping the physics
demands, and it does it cheaply. Other PDEs are \emph{globally coupled}: in
incompressible flow, the pressure at one point depends instantly on the entire
velocity field through a Poisson equation. A local machine simply cannot move
information fast enough; a global spectral operator like the FNO wins. Still other
PDEs have \emph{source terms} that create or destroy the quantity you were trying to
conserve (a reaction term), so building in conservation is actively harmful. And some
PDEs are \emph{stiff and bounded} (a 4th-order Cahn--Hilliard order parameter living
in $[-1,1]$), where the danger is not locality but numerical blow-up, and the cure is
to bound the output. Once you see PDEs this way, ``NCA vs PINN vs operator'' stops
being the right question. The right question is: \emph{which inductive bias matches
this PDE's personality?}

\paragraph{Contributions.} This paper makes the following contributions, each grounded
in the project's own multi-seed and single-seed benchmark results:
\begin{enumerate}
  \item A \textbf{correctness-gated JAX migration} of a PyTorch PI-NCA codebase, in
        which every ported solver and model is asserted equal to a verbatim reference
        before any architecture work begins (56/56 tests; a real NHWC-axis Laplacian
        bug and a Gray--Scott $dt=2.0$ instability were caught in the process).
  \item A \textbf{regime map} over ten 2-D phenomena and six 3-D phenomena, run under
        one shared autoregressive-emulation protocol, showing that no single
        architecture dominates and that the PDE's structure picks the winner.
  \item Four \textbf{motivated hybrid architectures} that compose the matching
        inductive biases and \emph{beat every pure baseline in their regime}: a
        multi-scale conservative NCA on smooth local transport (beats FNO at $\sim$1\%
        of its parameters) and a bounded conservation-preserving NCA on stiff
        Cahn--Hilliard (the only model that is both accurate \emph{and}
        mass-conserving).
  \item A \textbf{six-ablation study} (A1--A6) that isolates which component matters
        in which regime: conservation, output bounding, perception size, multi-step
        training, spectral mixing, and parameter count.
  \item A \textbf{spectral error diagnostic} that explains the NCA-vs-FNO trade in
        terms of where each model places its error in frequency space.
  \item A demonstration that the entire \textbf{regime map is dimension-independent},
        reproducing in full 3-D.
\end{enumerate}

\paragraph{Honesty caveats up front.} All experiments here are \emph{reduced-scale}
and run on a single CPU (no GPU was available on the host). Absolute numbers are
therefore not GPU-scale; the object of study is the \emph{relative ordering} of
architectures, which is the part expected to transfer when the identical configs are
re-run at full scale. We report a single fixed seed (42) under a ``start from a better
point'' protocol that matches the original implementations, and we are explicit
(Section~\ref{sec:limitations}) about the variance trade-off that this entails.

\section{Related Work}
% ============================================================

\paragraph{Neural Cellular Automata.} NCAs maintain a state grid and apply an
identical learned local rule to every cell, perceiving the neighborhood with fixed or
learned depthwise convolutions and updating through a pointwise MLP. The canonical
differentiable NCA is \emph{Growing Neural Cellular Automata}
\cite{mordvintsev2020growing}; the classical link between cellular automata and PDEs
predates it \cite{omohundro1003}. Subsequent work extended NCAs to textures and
continuous space-time dynamics (NoiseNCA \cite{noisenca}, $\mu$NCA
\cite{munca}, DyNCA \cite{dynca}), to geometric robustness (isotropic
\cite{isonca}, steerable \cite{steerablenca}), and surveyed the frontier
\cite{cellstopixels,universalnca,neuralparticle,difflogic}. For hardware
acceleration, CAX \cite{cax} provides a JAX library of CA primitives, which we
evaluate directly (Section~\ref{sec:cax}).

\paragraph{Physics-Informed Neural Networks.} PINNs \cite{raissi2019pinn1,
raissi2019pinn2} train a network $u_\phi(x,t)$ to satisfy the PDE residual through
autodiff, with no labelled interior data. Their strengths (mesh-free, continuous,
data-free) and pathologies (spectral bias, loss-balancing, causality) are by now
well documented \cite{pinnreview,adaptivepinn,pinnlimits,autobalance,causalpinn,
fourierfeatures,spectralbias,preconditioning,pinnerror}.

\paragraph{Neural operators.} The FNO \cite{li2020fno} learns a map between function
spaces via spectral convolution, achieving a global receptive field in one layer;
universality and generalization analyses followed \cite{neuraloperator,fno_universal,
fno_rademacher}, as did a physics-informed variant (PINO \cite{pino}). DeepONet
\cite{lu2019deeponet} factorizes the operator into a branch (input function) and trunk
(query location) network \cite{pideeponet,resdeeponet,statoperator}. Graph neural
operators \cite{gno,egno} target irregular meshes; we use regular periodic grids, so
they are noted only for completeness.

\paragraph{Differentiable solvers and JAX SciML.} End-to-end gradients through a
numerical solver enable hybrid learning and inverse design \cite{torax,implicitneural,
diffsolverrom}; our heat solver \emph{is} exactly a differentiable solver used as a
teacher. The autoregressive-emulator setting we benchmark is the one formalized by
APEBench/Exponax \cite{apebench}. The JAX ecosystem (jit/vmap/scan/sharding, Flax,
Optax) underpins the migration.

\paragraph{Positioning.} Prior work tends to advocate for one family. We instead run
all families through one protocol and ask the regime question, treating the hybrids as
\emph{testable hypotheses}, not assumed wins.

\section{Problem Setting and PDE Suite}
\label{sec:problem}
% ============================================================

We study time-dependent PDEs of the form
\begin{equation}
  \frac{\partial u}{\partial t} = \mathcal{N}[u;\,\theta_{\mathrm{phys}}],
  \quad x \in \Omega,\; t\in[0,T], \qquad
  \mathcal{B}[u]=0 \text{ on } \partial\Omega,\quad u(x,0)=u_0(x),
\end{equation}
where $\mathcal{N}$ is a (possibly nonlinear) spatial operator and the domain is a
periodic grid. Two \emph{learning problems} must not be conflated:
\begin{itemize}
  \item \textbf{Solving one IVP} (the PINN's native setting): fit $u(x,t)$ for a
        \emph{single} $u_0,\theta_{\mathrm{phys}}$.
  \item \textbf{Learning the solution operator} (the operator/NCA-emulator setting):
        learn a one-step map $u(t)\mapsto u(t+\Delta t)$ that \emph{generalizes across}
        initial conditions.
\end{itemize}
The NCA learns a \emph{local one-step update} trained to imitate a numerical solver ---
it is an \emph{autoregressive neural emulator}. PINNs and emulators are therefore not
measured on the same axis unless the protocol is designed carefully; we keep them as
separate paradigms (Section~\ref{sec:operators}).

\subsection{The equations}

\paragraph{Heat / diffusion (smooth, local, conservative).}
\begin{equation}
  \partial_t u = \alpha \nabla^2 u .
\end{equation}
The archetypal local, conservative parabolic PDE: total heat is conserved, and the
update is a discrete Laplacian --- a perfect match for a local stencil.

\paragraph{Advection--diffusion (linear transport).}
\begin{equation}
  \partial_t u = -\,\mathbf{c}\cdot\nabla u + \alpha\nabla^2 u .
\end{equation}
Smooth but with a global drift; conservation matters second to transport accuracy.

\paragraph{Allen--Cahn (non-conservative phase separation).}
\begin{equation}
  \partial_t u = \varepsilon^2 \nabla^2 u - W'(u), \qquad W'(u)=u^3-u,
\end{equation}
which develops \emph{sharp interfaces} --- fine-scale content that punishes spectral
smoothing.

\paragraph{Wave (2nd-order hyperbolic).}
\begin{equation}
  \partial_{tt} u = c^2 \nabla^2 u,
\end{equation}
written as a first-order system in $(u,\partial_t u)$ for emulation.

\paragraph{Shallow-water (conservative, multi-field).} Hyperbolic conservation laws in
$(h, hu, hv)$ on a periodic domain, where both mass and momentum are conserved ---
the multi-channel conservative regime.

\paragraph{Nagumo / FitzHugh--Nagumo (non-conservative reaction).} The bistable Nagumo
reaction--diffusion,
\begin{equation}
  \partial_t u = D\nabla^2 u + u(1-u)(u-a),
\end{equation}
and the two-field excitable FitzHugh--Nagumo activator--inhibitor system. The reaction
\emph{source term} changes total mass, so conservation is the \emph{wrong} prior.

\paragraph{Cahn--Hilliard (stiff, 4th-order, bounded).}
\begin{equation}
  \partial_t u = \nabla^2\!\left(-\varepsilon^2\nabla^2 u + W'(u)\right),
\end{equation}
a 4th-order, stiff, mass-conserving PDE whose order parameter is bounded in $[-1,1]$.
This is the regime where naive emulators \emph{blow up}.

\paragraph{Gray--Scott (reaction--diffusion patterns).}
\begin{align}
  \partial_t u &= D_u\nabla^2 u - uv^2 + F(1-u),\\
  \partial_t v &= D_v\nabla^2 v + uv^2 - (F+k)v,
\end{align}
a notoriously hard pattern-forming system (we use the stable $dt=1.0$ teacher; the
verbatim $dt=2.0$ diverges, as logged during migration).

\subsection{Three-dimensional suite}
Six of these (heat, advection--diffusion, Allen--Cahn, Nagumo, Gray--Scott,
FitzHugh--Nagumo) are re-implemented in full 3-D on an $16^3$ grid in NDHWC layout, with
a 7-point Laplacian, a 3-D flux divergence over all three axes, and a 3-D spectral
convolution via \texttt{rfftn} (Section~\ref{sec:threed}).

\section{Methods}
\label{sec:methods}
% ============================================================

\subsection{JAX migration and the correctness gate}
\label{sec:gate}

Before any new science, the entire PyTorch codebase (solvers and models) was ported to
JAX/Flax and \emph{asserted equal to verbatim PyTorch references to tolerance}. This
correctness gate is the foundation of every later claim: if the JAX heat solver does
not match the PyTorch one, no benchmark built on it can be trusted. The gate caught two
genuine bugs:
\begin{itemize}
  \item a real \textbf{NHWC-axis bug} in the heat Laplacian (an isotropy violation),
        fixed and re-asserted;
  \item a \textbf{Gray--Scott $dt=2.0$ instability} in the verbatim parameters, which
        diverges; the benchmarks use the stable $dt=1.0$ teacher.
\end{itemize}
The gate stands at \textbf{56/56} tests (36 for the 2-D migration/suite/metrics, 11 for
the 3-D correctness suite, plus additional smoke/training checks), and must be green
before any benchmark is trusted. Determinism flows entirely from explicit
\texttt{jax.random.PRNGKey(seed)} values; correctness is asserted to tolerances rather
than bit-equality because XLA CPU reductions are not bitwise-deterministic across
thread counts.

\subsection{Architectures and their update equations}
\label{sec:arch}

All neural emulators are used as \emph{one-step autoregressive maps}
$g_\theta:\, \mathrm{state}_t \mapsto \mathrm{state}_{t+1}$, trained by distillation
against a differentiable solver teacher and rolled out with \texttt{jax.lax.scan}. The
PINN is the exception (continuous, single-IVP). All update heads are zero-initialized,
so every model \emph{starts as the identity map} --- a warm start.

\paragraph{(A) Plain NCA.} Perceive with a learnable $3\times3$ circular convolution
$P(\cdot)$, then a per-cell MLP (a stack of $1\times1$ convolutions) produces a residual
increment:
\begin{equation}
  s_{t+1} = s_t + \mathrm{MLP}\!\big(\mathrm{ReLU}(P(s_t))\big).
\end{equation}
The residual ``$+s_t$'' makes the rule an explicit Euler step of a learned dynamical
system. There is \emph{no} conservation constraint. Cost is $O(N C F)$ per step
(linear in the number of cells $N$ for hidden width $F$). \textbf{Strength:} locality
and translation-equivariance match local PDE stencils, and it is cheap.
\textbf{Weakness:} no conservation means mass/energy drift, and locality means slow
global-information propagation and long-horizon error accumulation.

\paragraph{(B) Conservative PI-NCA (DeepFluxNCA).} Same perceive+MLP backbone, but the
head predicts a \emph{flux field} $(f_x,f_y)$ and the update is its discrete
divergence:
\begin{equation}
  s_{t+1} = s_t + \big(\mathrm{roll}(f_x)-f_x\big) + \big(\mathrm{roll}(f_y)-f_y\big).
  \label{eq:flux}
\end{equation}
Summed over a periodic grid, the increment \emph{telescopes to zero}, so mass is
conserved \emph{by construction} (this is exactly a finite-volume flux form).
Empirically the heat conservation error is $\sim$$10^{-4}$ versus $\sim$$10^{1}$ for an
unconstrained model. \textbf{Strength:} exact discrete conservation and strong
long-horizon mass behavior at the same cheap locality. \textbf{Weakness:} still local,
and it conserves mass but not necessarily the \emph{correct rate} --- it can conserve
the wrong dynamics.

\paragraph{(C) MultiScaleFluxNCA (the heat-regime hybrid).} Perceive at three dilations
($d=1,2,4$), concatenate, then apply the conservative flux head of
Eq.~\eqref{eq:flux} with an optional bounding step:
\begin{equation}
  s_{t+1} = \mathcal{C}\Big[\,s_t + \mathrm{div}\big(\mathrm{flux}(\,
  [\,P_{d=1}(s_t)\,\|\,P_{d=2}(s_t)\,\|\,P_{d=4}(s_t)\,]\,)\big)\Big],
\end{equation}
where $\mathcal{C}$ is identity when \texttt{bounds=None} and a clip-plus-mass-reproject
when bounds are set. Dilations $1/2/4$ widen the receptive field to $\pm4$ cells per
step (versus $\pm1$ for a single $3\times3$), closing the locality gap cheaply --- which
is why it beats FNO on heat at $\sim$1\% of the parameters.

\paragraph{(D) BoundedConsFluxNCA (the Cahn--Hilliard-regime hybrid).} Records the total
mass, applies the conservative flux update, \emph{clips} the state to its physical range
$[-1,1]$ (stabilizing it but breaking conservation), then \emph{re-projects} to restore
the recorded total mass:
\begin{equation}
  \tilde s = \mathrm{clip}\big(s_t + \mathrm{div}(\mathrm{flux}(\dots)),\,-1,1\big),
  \qquad
  s_{t+1} = \mathrm{conserve\_energy}\big(\tilde s,\ \textstyle\sum s_t\big).
\end{equation}
This resolves the stability$\leftrightarrow$conservation tension discovered in ablation
A1 (Section~\ref{sec:ablation}): clipping alone fixes blow-up but destroys conservation;
the mass re-projection restores it, yielding a model that is bounded \emph{and}
conserving.

\paragraph{(E) SpectralFluxNCA (two-stream local+global).} A local conservative stream
(perceive $\to$ flux $\to$ divergence, conserving mass) is added to a global FNO-style
spectral stream (lift $\to$ \texttt{[SpectralConv2d + $1\times1$]}$\times$depth $\to$
project, zero-initialized):
\begin{equation}
  s_{t+1} = \underbrace{s_t + \mathrm{div}(\mathrm{flux}(\dots))}_{\text{local, conserving}}
            \;+\; \underbrace{g_\theta^{\text{spectral}}(s_t)}_{\text{global, FNO-style}} .
\end{equation}
The global stream gives $O(1)$-layer global reach at the cost of $\sim$134k parameters.

\paragraph{(F) MultiChannelFluxNCA (per-field conservation).} For multi-field PDEs,
the flux head emits $2C$ channels --- a flux $(f_x,f_y)$ per field --- and each field's
mass is conserved by its own per-channel divergence. This is the \emph{correct} prior
for periodic conservation laws (shallow-water mass+momentum) and a deliberately
\emph{wrong} prior for source-term reaction systems (FitzHugh--Nagumo).

\paragraph{(G) Fourier Neural Operator (FNO).} Each layer mixes a pointwise linear map
with a truncated spectral convolution:
\begin{equation}
  v_{l+1} = \sigma\!\Big( W v_l + \mathcal{F}^{-1}\big(R_l \odot \mathcal{F}[v_l]\big)\Big),
\end{equation}
truncating to the lowest $m\times m$ Fourier modes. \textbf{Strength:} global,
multiscale mixing in few layers; resolution-invariant; native to periodic grids.
\textbf{Weakness:} spectral truncation smooths sharp features, and the spectral weights
are large ($\sim$$5.9\times10^5$ params here, versus the NCAs' $\sim$$5\times10^3$).

\paragraph{(H) PINN.} A continuous network $u_\phi(x,t)$ minimizing a residual loss via
autodiff:
\begin{equation}
  \mathcal{L} = \lambda_r\big\|\partial_t u_\phi - \mathcal{N}[u_\phi]\big\|^2
              + \lambda_b\big\|\mathcal{B}[u_\phi]\big\|^2
              + \lambda_0\big\|u_\phi(\cdot,0)-u_0\big\|^2 .
\end{equation}
Mesh-free, no labelled data, one IVP per training run. \textbf{Weakness:} spectral bias,
loss-balancing pathologies, no cross-IC reuse.

\paragraph{(I) DeepONet.} A branch network encodes the input function (at sensors) and a
trunk network encodes the query point; the output is their inner product,
$G(a)(y)\approx\sum_k b_k(a)\,t_k(y)$. It is an operator (cross-IC) trained on solver
pairs.

\subsection{Training protocol and the ``start from a better point'' recipe}
\label{sec:protocol}

Every emulator is trained identically: same teacher, same initial conditions, same
horizon, same optimizer (AdamW), and the same rollout-MSE loss. The \emph{only}
difference between runs is the architecture. The shared pipeline is: draw a random IC;
\emph{pre-seed} it by evolving it with the solver for \texttt{preseed\_steps}
(producing a developed state); roll out both the teacher and the model over $K$ steps;
compute MSE; update with value-and-grad through the whole trajectory (BPTT via
\texttt{lax.scan}); and finally evaluate on a longer horizon from held-out ICs.

The originals used a specific recipe we restore faithfully:
\begin{itemize}
  \item \textbf{Single fixed seed (42)} --- the originals used \texttt{manual\_seed(42)}
        with no multi-seed averaging.
  \item \textbf{He / Kaiming-normal init} for ReLU-preceding convolutions.
  \item \textbf{Zero-init flux head} (identity start).
  \item \textbf{LR warmup} (linear$\to$constant schedule).
  \item \textbf{Pre-seeding} --- pre-evolve the IC into a developed state so the model
        trains on the hard developed-pattern regime, not just early diffusion.
\end{itemize}
An honest A/B (heat, \texttt{multiscale\_flux\_nca}, seed 42, 150 epochs) shows that
\emph{pre-seeding is the real ``better start''}: it improves accuracy
($0.0328\to0.0270$) and, more importantly, markedly improves long-horizon stability
(error-growth ratio $2.54\to1.41$). He-init and warmup are marginal here but kept for
fidelity. This protocol improved most PDEs over the prior multi-seed numbers (heat
spectral $0.016\to0.0064$, SWE \texttt{mc\_flux}$\to0.016$, NS \texttt{fno}
$0.145\to0.098$, wave $0.108\to0.052$) but \emph{hurt} Cahn--Hilliard --- pre-seeding
mismatches its fresh-IC coarsening --- so CH uses \texttt{preseed\_steps=0}. The
\emph{orderings} are stable; only exact numbers shift. Figure~\ref{fig:pipeline}
sketches the shared pipeline.

\section{Experimental Setup}
\label{sec:setup}
% ============================================================

\paragraph{Task.} One-step autoregressive emulation of a PDE solver teacher. Each model
is trained to match the teacher's \texttt{rollout\_steps}-step rollout from random ICs,
then evaluated on a longer \texttt{eval\_steps} horizon from held-out ICs (a different
PRNG stream) --- testing temporal generalization. The reduced-scale CPU presets are
typically grid $24$ (2-D) or $16^3$ (3-D), train $12$ / eval $48$ steps, 150--200
epochs.

\paragraph{Metrics.} We compute a full 20-metric panel for every phenomenon:
rel-L2 (primary accuracy), MSE, RMSE, MAE, $L^\infty$, PSNR, SSIM, a
\emph{high-frequency error fraction} (how much of the error lives in fine scales), an
\emph{error-growth profile} (rel-L2 at $T/4, T/2, 3T/4, T$ and the growth ratio),
mass-conservation error ($|\mathrm{mass}(\mathrm{pred})-\mathrm{mass}(\mathrm{IC})|$),
periodic-BC residual, gradient-energy (a stability proxy), parameter count, training
wall-clock, inference seconds/step, and throughput (cells/s).
Table~\ref{tab:heat20} gives the full panel for heat to make the protocol concrete.

\paragraph{Reduced-scale CPU honesty.} The host is a single CPU (no GPU; Python 3.14.5,
jax 0.10.1 CPU build). Grids, horizons, epochs, and seed counts are small. Absolute
numbers are therefore not GPU-scale, and \texttt{pmap}/sharding paths are no-ops on a
single device. The \emph{relative} architecture orderings are the object of study and
are the part expected to transfer; the only difference between the CPU and GPU presets
is numeric config fields, so the identical code re-runs at full scale.

\subsection{Smooth local diffusion: NCAs win (heat)}
On heat, the local/multi-scale conservative NCAs win. Under the better-start protocol
the \texttt{spectral\_flux\_nca} reaches rel-L2 $0.0064$, the \texttt{multiscale} reaches
$0.027$, and even the plain conservative \texttt{pi\_nca} ($0.031$) edges the FNO
($0.021$ better-start; $0.0352$ in the multi-seed run). The intuition is direct:
diffusion \emph{is} a local stencil, so a local conservative machine has exactly the
right bias. In the multi-seed run (Table~\ref{tab:heatms}), the \texttt{multiscale}
hybrid is best at $0.0183\pm0.0016$, beating FNO ($0.0352$) and the plain conservative
PI-NCA ($0.0438$) at $\sim$110$\times$ fewer parameters, with the plain unconstrained NCA
diverging ($0.234$). \textbf{Conservation is what makes the local NCA viable here}: the
unconstrained NCA's mass error is $33$, while the flux-divergence form conserves to
$3.8\times10^{-4}$ --- five orders of magnitude better, by construction.

\subsection{Globally-coupled flow: FNO wins (Navier--Stokes)}
The complement of heat. Incompressible 2-D vorticity has a \emph{global} Poisson
coupling ($\nabla^2\psi=-\omega$): the velocity at every point depends on the entire
vorticity field. A local NCA cannot move information fast enough, and indeed the FNO
wins decisively (rel-L2 $0.145$ multi-seed; $0.098$ better-start) versus the best NCA
($0.284$, multi-scale). Among NCAs the \emph{multi-scale} one is best because its
dilated perception partially captures the non-locality; the single-stencil plain
($0.528$) and conservative \texttt{pi\_nca} ($0.676$) lag badly. \textbf{The PDE's
information-propagation structure picks the architecture}: locality+multi-scale wins
purely local diffusion; global spectral wins globally-coupled flow.

\subsection{Fine-scale / sharp interfaces: FNO wins (Allen--Cahn)}
Allen--Cahn develops sharp interfaces --- fine-scale content. The FNO wins ($0.0068$),
with the NCAs around $0.049$. This connects directly to the spectral diagnostic below:
the NCAs over-smooth, so they pay most where the solution is sharpest.

\subsection{Non-conservative reaction: the unconstrained NCA wins (Nagumo, FHN)}
On Nagumo and FitzHugh--Nagumo the reaction \emph{source term} changes total mass, so the
conservation prior is structurally wrong. The unconstrained \texttt{plain\_nca} wins
(Nagumo $0.073$/$0.118$ multi-seed; FHN $0.125$/$0.154$ multi-seed), while the conserving
models stall (Nagumo $0.379$; FHN \texttt{mc\_flux} $0.993$ --- it conserves total $u,v$
perfectly at $1.1\times10^{-6}$ while being useless). \textbf{Conservation is only an
asset when the PDE is conservative.}

\subsection{Conservative multi-field: per-field conservation wins (shallow-water)}
On periodic shallow-water, mass \emph{and} momentum are conserved, so the per-channel
flux prior is correct. The \texttt{mc\_flux\_nca} ties the FNO on accuracy
($0.031$ vs $0.026$) at $54\times$ fewer parameters, with conservation four orders better
($1.6\times10^{-4}$ vs $0.77$). The FNO edges accuracy, but at 593k parameters.

\subsection{Stiff 4th-order: everyone fails, then bounding rescues (Cahn--Hilliard)}
This is the most instructive regime. \emph{Every} simple emulator \emph{diverges}:
against an identity ``do-nothing'' floor of rel-L2 $\approx 0.93$, the baselines score
$14$--$18$ --- they do not merely under-fit, they blow up over the $48$-step horizon
($4\times$ the $12$-step training horizon). The FNO's global mixing does \emph{not}
rescue it (it has catastrophic seed variance, $15\pm15$), refuting a naive ``global
operator is always better'' expectation. The conservative \texttt{pi\_nca} conserves
mass to $3\times10^{-5}$ while being the \emph{least} accurate --- it faithfully conserves
the wrong dynamics, a clean empirical demonstration that \emph{conservation $\ne$
correctness}. The fix (ablation A1) is to \emph{bound} the output; the
\texttt{bounded\_cons\_nca} hybrid then reaches $0.603$ (multi-seed) / $0.725$
(preseed=0 better-start), below the floor, \emph{and} conserves mass to
$2.4\times10^{-4}$ --- the only model that is both accurate and conserving.

\subsection{The spectral diagnostic: where the NCAs' error lives}
\label{sec:spectral}
Why does the FNO win sharp-interface problems despite the NCAs' lower \emph{total} error
on smooth ones? The high-frequency error fraction answers it. On heat, the NCAs place
$0.44$--$0.89$ of their error in fine scales, whereas the FNO's error is broadband-flat
at $0.004$ (multi-seed; $0.068$ in the single-seed panel of Table~\ref{tab:heat20}). The
NCAs are accurate overall but \emph{over-smooth} --- their residual error concentrates in
the highest frequencies. The FNO spreads its error evenly across the spectrum. This is
precisely \emph{why} the FNO wins Allen--Cahn and other fine-scale, sharp-interface
regimes: those solutions are dominated by exactly the fine scales the NCAs smear.

\subsection{Efficiency: the hybrid NCA is $\sim$200$\times$ more parameter-efficient}
\label{sec:efficiency}
Accuracy alone undersells the NCAs. Measuring the \emph{param-cost of accuracy} as
rel-L2$\times$params (lower is better), Table~\ref{tab:eff} shows the hybrid multi-scale
NCA at $101$ versus the standard FNO at $20{,}875$ --- a $207\times$ gap. The hybrid is
simultaneously \emph{more accurate} ($0.0183$ vs $0.0352$) and $107\times$ smaller (5.5k
vs 593k params), and roughly $6\times$ cheaper at inference (Table~\ref{tab:heat20}).
The FNO buys a global receptive field --- essential on globally-coupled PDEs --- at a
large parameter and compute premium.

% ============================================================
\section{Ablation Studies}
\label{sec:ablation}
% ============================================================

The ablations isolate \emph{which component} drives performance, and confirm that the
answer is regime-dependent. Table~\ref{tab:ablsummary} summarizes.

\paragraph{A1 --- Output bounding (Cahn--Hilliard).} Clipping each emulator step to the
field's physical range $[-1,1]$ (as the solver does) takes the NCAs from catastrophic
divergence to below the identity floor: \texttt{plain\_nca} $12.93\to0.540$ and
\texttt{pi\_nca} $16.51\to0.600$ --- a $24$--$27\times$ improvement. The CH failure was a
\emph{stability/blow-up} problem, architecturally fixable, not an intrinsic limit of
local emulation. But there is a catch: hard clipping \emph{destroys} the flux-NCA's exact
conservation ($3.3\times10^{-5}\to7.6$) --- clip is a non-conservative projection. So the
two desirable properties (boundedness, exact conservation) \emph{conflict}, which is
exactly what motivates the bounded conservation-preserving \texttt{bounded\_cons\_nca}.
Once clipping dominates, plain and conservative NCAs become statistically comparable
($0.54$ vs $0.60$): on stiff CH, \emph{bounding} matters more than \emph{conservation} for
accuracy --- reversing the heat ranking.

\paragraph{A2 --- Iso-parameter FNO (heat).} Shrinking the FNO to the NCA budget
($8.4$k params) degrades it $3.4\times$ ($0.035\to0.119$), making it worse than both
NCA-budget models. \textbf{The FNO's heat edge was largely parameter count, not spectral
mixing per se}; the multi-scale NCA beats both full and iso-param FNO at $\sim$1\% of the
parameters.

\paragraph{A3 --- Horizon curriculum (Cahn--Hilliard).} Matching the training horizon to
the eval horizon ($12\to24\to48$) cuts rel-L2 $0.633\to0.619\to0.511$ ($\sim$19\%
relative) and conservation error $3.2\times10^{-4}\to6.8\times10^{-5}$. The train/eval gap
was a real, \emph{separate} contributor on top of bounding (A1). The combined recipe ---
bounded+conserving and train$\approx$eval --- reaches CH $0.51$, well below the floor,
with near-exact conservation.

\paragraph{A4 --- Conservation on/off at matched width.} With the \emph{same} backbone and
only the head differing (flux/conserving vs residual/free), conservation \emph{helps} heat
($0.104$ vs $0.353$, $3.4\times$) and \emph{hurts} Nagumo ($0.379$ vs $0.123$,
$3.1\times$). This is the clean, matched-width proof of the central rule: the
conservation head helps when the PDE conserves mass and hurts when it does not.

\paragraph{A5 --- Perception / receptive-field size.} Widening perception (3$\times$3 vs
5$\times$5 vs dilated multi-scale 1/2/4) helps both regimes, but \emph{how} matters: on
heat all three improve with reach ($0.104\to0.046\to0.024$); on globally-coupled
Navier--Stokes, a plain 5$\times$5 stencil \emph{destabilizes} ($1.486$, worse than
3$\times$3's $0.576$) while dilated multi-scale is best ($0.388$). \textbf{Multi-scale
dilation is the robust way to widen reach.}

\paragraph{A6 --- Single- vs multi-step (BPTT) training.} Training through the trajectory
(rollout 1/4/12) is \emph{nearly irrelevant} on stable heat ($0.0250\to0.0210$, 16\%) but
\emph{decisive} on unstable Navier--Stokes: single-step-trained emulators diverge
($1.562$, error-growth $13.5\times$) while 12-step training stabilizes the long rollout
($0.284$, error-growth $2.76\times$) --- a $5.5\times$ gain. \textbf{The model must see its
own accumulated error during training to control it}, and this matters most exactly where
the dynamics are hardest.

\section{Continuous and Operator Baselines}
\label{sec:operators}
% ============================================================

The PINN and DeepONet solve a \emph{different task} from the emulators --- a single IVP
(PINN) or a fixed-horizon operator (DeepONet) --- and are scored on a different horizon.
They are reported as within-paradigm baselines, \emph{not} a head-to-head accuracy race
(Table~\ref{tab:operators}).

On heat, DeepONet ($0.075$) clearly beats the PINN ($0.208$): it is an operator trained
on solver data that generalizes across initial conditions, whereas the vanilla PINN
solves one IVP from the equation alone and pays the spectral-bias/loss-balancing tax. The
trade is clear: the PINN needs \emph{zero training data} and is mesh-free and continuously
queryable; DeepONet needs solver pairs but is far more accurate and trains in seconds.
Neither matches the best autoregressive emulator's rollout accuracy on heat, but the
metrics are not commensurable.

\paragraph{Darcy flow (steady elliptic operator $a\mapsto u$).} On a high-contrast
piecewise coefficient Darcy problem (grid 20, 256 train samples), both models are
mediocre, but the \textbf{learned-iterative NCA solver edges the FNO at $144\times$ fewer
parameters} ($0.535$, 4.1k params vs $0.594$, 593k params). Relaxing $u$ from zero over
24 local steps is a natural fit for an elliptic solve (akin to a learned Jacobi/multigrid
smoother), and over a 20-grid, 24 steps nearly suffices to propagate boundary information.
The FNO trains $5\times$ faster (no inner rollout). The honest reading: \emph{locality is
not disqualifying on a static elliptic problem the way it is on dynamic Navier--Stokes}.

\section{CAX Accelerator Evaluation}
\label{sec:cax}
% ============================================================

We evaluated whether the CAX library (Cellular Automata Accelerated in JAX,
\texttt{arXiv:2410.02651}) could speed up our rollouts. The key observation is that CAX's
rollout driver is \texttt{nnx.scan} + \texttt{nnx.jit} --- \emph{structurally identical}
to our hand-written \texttt{jax.lax.scan} rollout; both compile to the same XLA scan.
There is no separate kernel or hardware path that would make CAX intrinsically faster on
the same device. A measurement (single CPU, grid 32, 64 steps, batch 8) gives our
\texttt{lax.scan} \texttt{DeepFluxNCA} ($C=1$) at $\sim$1.17 ms/step versus a CAX
\texttt{ComplexSystem} NCA ($C=16$ + hidden) at $\sim$2.42 ms/step --- though this is not
param-matched (the CAX NCA does more work). \textbf{CAX gives no single-CPU rollout
speedup}; its value is its CA zoo (Lenia, Flow-Lenia), its ready-made Moore/von-Neumann
perception stencils (useful as A5 neighbourhood variants), and multi-device scaling when
hardware exists. We therefore did not integrate it into the hot path, but keep a working
CAX NCA subclass as a reference integration point.

\section{Discussion}
\label{sec:discussion}
% ============================================================

The central thesis is now well supported: \textbf{there is no universal winner}, and the
PDE's structure --- conservation, boundedness, information-propagation range, and
fine-scale content --- selects the architecture.

\begin{itemize}
  \item \textbf{Conservation} helps iff the PDE is conservative. It makes the local NCA
        viable on heat (the unconstrained NCA diverges) and lets a tiny per-field
        conservative NCA tie the FNO on shallow-water; it actively \emph{hurts}
        non-conservative reaction systems (Nagumo, FHN), where it conserves the wrong
        totals. A4 proves this at matched width.
  \item \textbf{Information-propagation range} decides locality vs global. Heat (purely
        local) and Navier--Stokes (global Poisson) are mirror images: locality+multi-scale
        wins the former, global spectral wins the latter.
  \item \textbf{Fine-scale content} explains the spectral diagnostic: NCAs over-smooth
        (high-frequency error fraction $0.44$--$0.89$) while the FNO is broadband-flat
        ($0.004$), so the FNO wins sharp-interface problems (Allen--Cahn) despite the NCA's
        lower total error on smooth ones.
  \item \textbf{Boundedness / stiffness} is its own axis. On Cahn--Hilliard the failure is
        blow-up, not locality, and the cure is output bounding --- which then conflicts with
        conservation and forces a bounded conservation-preserving design.
\end{itemize}

\textbf{The hybrids win their regime --- empirically, not by assumption.} A model that
composes the matching biases beats every pure baseline in its regime: the multi-scale
conservative NCA wins smooth local diffusion (beats FNO at $\sim$1\% of its parameters),
and the bounded conservation-preserving NCA wins stiff Cahn--Hilliard (the only model both
accurate and conserving). Crucially, \emph{stacking all components is not automatically
better}: multi-scale perception helps smooth transport but not stiff-CH accuracy (there,
bounding is what matters). A single unified \texttt{MultiScaleFluxNCA} with
PDE-appropriate bounds is best-or-near-best in both regimes (\texttt{bounds=None} wins
heat; \texttt{bounds=(-1,1)} ties the CH winner at $\sim$6$\times$ lower variance). The
conservative NCA's flux-divergence structure is the key reusable component --- cheap,
exactly mass-conserving, and composable with wider perception or bounding as the PDE
demands.

For PDE-governed systems, then, ``NCA vs PINN vs operator'' is the wrong framing. The
right framing is \emph{which inductive bias matches the PDE's character}: locality +
conservation for smooth local transport; global spectral mixing for cross-IC
generalization on periodic grids; explicit boundedness/stabilization for stiff dynamics;
and continuous mesh-free PINNs for single-IVP or irregular-query problems.

% ============================================================
\section{Limitations}
\label{sec:limitations}
% ============================================================

\begin{itemize}
  \item \textbf{Reduced-scale CPU.} Small grids, horizons, epochs, and seed counts on a
        single CPU (no GPU). Absolute numbers are not GPU-scale;
        \texttt{pmap}/sharding paths are no-ops on one device. The relative orderings are
        the object of study, and the identical configs re-run at full scale by changing
        only numeric fields.
  \item \textbf{Single-seed trade-off.} Headline numbers use a single fixed seed (42) per
        the originals' recipe. This is deterministic and reproducible but a single seed can
        be lucky/unlucky (e.g.\ multiscale on heat was $0.021$ as the mean of seeds 0,1 vs
        $0.033$ at seed 42). We retain a \texttt{--seeds N} variance study and report
        multi-seed mean$\pm$std where it was run, and lean on init-robust signals
        (error-growth, spectral diagnostics) where a single number could mislead.
  \item \textbf{Protocol caveat for Cahn--Hilliard.} Pre-seeding helps most PDEs but
        mismatches CH's fresh-IC coarsening, so CH uses \texttt{preseed\_steps=0}.
  \item \textbf{PINN/DeepONet are heat-only} and use different horizons/metrics than the
        emulators; they are a separate paradigm, not a head-to-head.
  \item \textbf{Some sweeps remain.} A handful of emulator sweeps are scaffolded but not
        exhaustively run; all are reproducible from \texttt{bench.py}.
\end{itemize}

% ============================================================
\section{Conclusion}
% ============================================================

We set out to ask whether a local PI-NCA can beat PINNs and neural operators on PDEs, and
answered it without spin: \emph{sometimes, and it depends entirely on the PDE}. Across ten
2-D and six 3-D phenomena under one shared protocol, no architecture wins everywhere. The
PDE's structure --- conservation, boundedness, information-propagation range, and
fine-scale content --- selects the architecture, and hybrids that compose the matching
inductive biases beat every pure baseline in their regime: a multi-scale conservative NCA
on smooth local transport (more accurate than an FNO at $\sim$200$\times$ better parameter
efficiency) and a bounded conservation-preserving NCA on stiff dynamics (the only model
both accurate and mass-conserving). The result is dimension-independent. The practical
takeaway for practitioners is a decision rule rather than a champion: read the PDE's
personality, and pick (or compose) the inductive bias that matches it.

\section{Reproducibility}
\label{sec:repro}
% ============================================================

All results are reproducible from the project repository (branch
\texttt{research/jax-migration}). The verified stack is jax 0.10.1 (CPU), flax 0.12.7,
optax 0.2.8, cax 0.3.3, torch 2.12.0 (CPU, reference only), Python 3.14.5 on Windows 11
(no GPU). Determinism flows from explicit \texttt{jax.random.PRNGKey(seed)}; correctness
is asserted to tolerances, not bit-equality (XLA CPU reductions are not bitwise
deterministic across thread counts).

\begin{verbatim}
# Correctness gate (run first; must be green) -- 56/56 total
python -m pytest tests/ -q                         # 2-D migration/suite/metrics (36)
python -m pytest tests/test_pde3d_correctness.py -q # 3-D correctness gate (11)

# Reproduce a 2-D benchmark (multi-seed, mean +/- std)
python -m pinca_jax.bench --pde heat --seeds 3 --epochs 200 --grid 24 \
    --rollout 12 --eval 48
python -m pinca_jax.bench --pde cahn_hilliard --seeds 3 --epochs 200 --grid 24

# Reproduce the 3-D benchmarks
python -m pinca_jax.bench3d --grid 16 --epochs 120

# Continuous baselines and CAX evaluation
python -m pinca_jax.pinn_heat
python -m pinca_jax.cax_eval
\end{verbatim}

Available PDEs: \texttt{heat, wave, adv\_diff, allen\_cahn, gray\_scott, shallow\_water,
cahn\_hilliard, fitzhugh\_nagumo}. Each run writes \texttt{results/bench\_<pde>.json} and a
markdown table; the full 20-metric panels live in \texttt{results/bench\_<pde>\_full.md}.
Only the numeric config fields differ between the reduced-scale CPU presets and full-scale
GPU presets, so the same code reproduces both.
